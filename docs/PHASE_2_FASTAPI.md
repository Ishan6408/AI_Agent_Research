# PHASE 2: FastAPI Backend

## 1. New Backend Architecture
The backend introduces a FastAPI API layer that wraps the existing simulation, analyzer, and storage functionality.
```
React UI -> FastAPI API -> Service Layer -> Existing Python Components -> Results
```

## 2. Folder Structure
- `backend/main.py`: FastAPI application entry point.
- `backend/core/`: Configuration files (e.g., `config.py` for CORS, project settings).
- `backend/schemas/`: Pydantic models defining request and response payloads.
- `backend/services/`: Service layer implementing business logic, calling existing components.
- `backend/routes/`: FastAPI routers grouping endpoints by domain.

## 3. API Endpoint List
- `GET /api/health`
- `GET /api/experiments`
- `GET /api/experiments/{experiment_id}`
- `POST /api/experiments/run`
- `POST /api/experiments/run-pressure`
- `POST /api/experiments/run-all`
- `GET /api/dataset`
- `GET /api/dataset/summary`
- `GET /api/dataset/export`
- `GET /api/analytics/overview`
- `GET /api/analytics/pressure`
- `GET /api/analytics/personality`
- `GET /api/analytics/developers`
- `GET /api/analytics/behavior`
- `GET /api/analytics/correlation`
- `GET /api/analytics/suspicious`
- `GET /api/analytics/auditor`
- `GET /api/agents`
- `GET /api/agents/{role}`
- `GET /api/auditor/results`
- `POST /api/auditor/audit`

## 4. Request Schemas
Defined in `backend/schemas/`. 
Examples include `RunPressureRequest(pressure: str, runs: int)`, `RunAllRequest(runs: int)`, and `RunExperimentRequest(pressure: str)`.

## 5. Response Schemas
- Agent API returns an `AgentResponse` schema exposing metadata without internal LLM state.
- Analytics and Dataset APIs return JSON serializations of the pandas dataframes and metrics generated by `ExperimentAnalyzer`.

## 6. Data Flow
Requests hit `routes`, are parsed via `schemas`, and handled by `services`. Services use `ExperimentRunner`, `ExperimentAnalyzer`, or `AuditorAgent` to fetch or compute data, falling back to JSON storage in `results/`. Results are returned as JSON via FastAPI.

## 7. How to Start FastAPI
Run from the root directory:
```bash
python -m backend.main
```
Or start Uvicorn directly:
```bash
uvicorn backend.main:app --reload
```

## 8. How to Test Endpoints
Test endpoints interactively by navigating to the Swagger UI:
`http://localhost:8000/api/docs`

## 9. CORS Configuration
Configured to support Vite development origin `http://localhost:5173` via `backend/core/config.py`.

## 10. Error Handling
- Exceptions like missing datasets raise a 404 HTTP exception.
- Validation errors for bad requests raise 400.
- Simulation crashes or read errors raise 500.

## 11. Known Limitations
- Background simulation blocking: Currently `POST /api/experiments/run` is synchronous and blocks the event loop since Ollama is invoked synchronously. Background processing via Celery or similar is omitted to keep Phase 2 simple.
